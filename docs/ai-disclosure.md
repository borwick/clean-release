# How this was written

`clean-release` was written with Claude Code.

## the level

**AI-generated with human prompting and review.** That is one of the four
levels in the W3C AI content disclosure vocabulary, and it is the one that
fits. No part of this tree is unreviewed output, and no part of it is
hand-written code an assistant only tidied.

## who did what

John Borwick directed the work, made every design call, and reviewed
every change before it landed. Claude Code wrote the code, the tests and
the documents. The model was Claude Opus 5.5.

## why the git history does not say it

Claude Code writes a `Co-Authored-By` trailer into each commit it makes.
The public history is one snapshot commit per release, which
`clean-release` cut from a private history, and those trailers did not
survive it. This page is where that record lives now.

## no endorsement

Anthropic did not build `clean-release`. Anthropic does not sponsor it, and
does not endorse it. Claude Code is Anthropic's tool, and it was used here
the way any tool is used.
